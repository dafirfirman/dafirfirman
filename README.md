## 👋 Tentang Saya | About Me

Halo! Saya **Firman Damai Zebua, S.Kom**, seorang software developer, pendidik, dan mahasiswa Magister Teknik Informatika di **Universitas Sumatera Utara (USU)**.

Saya mengajar Koding dan Kecerdasan Artifisial serta Pemrograman Dasar di **SMK Swasta YAPIM Biru-biru, Deli Serdang**. Saya senang mengembangkan aplikasi yang menyelesaikan permasalahan nyata sekaligus mengeksplorasi teknologi melalui penelitian dan pembelajaran berkelanjutan.

- 🎓 **Education:** S1 Teknik Informatika — Universitas Katolik Santo Thomas Medan.
- 🎓 **Currently:** S2 Magister Teknik Informatika — Universitas Sumatera Utara.
- 👨‍🏫 **Teaching:** Koding dan Kecerdasan Artifisial, Pemrograman Dasar.
- 💻 **Software Development:** Web applications, mobile applications, REST APIs, and database systems.
- 🤖 **Research Interests:** Machine Learning, DDoS Detection, Cybersecurity, NLP, and Blockchain.
- 📱 **Mobile Development:** Flutter and Dart.
- 🌐 **Web Development:** PHP, MySQL, JavaScript, React, and Next.js.
- 🎯 **Long-Term Goal:** Menjadi dosen dan peneliti di bidang Informatika.
