## 👨‍💻 About Me

Hello! I'm **Firman Damai Zebua, S.Kom**, a software developer, educator, and postgraduate student in Informatics Engineering at **Universitas Sumatera Utara (USU), Indonesia**.

I enjoy building practical digital solutions that combine clean code, modern technologies, and real-world problem-solving.

- 🎓 **Education:** Master's Student in Informatics Engineering — Universitas Sumatera Utara (USU).
- 💻 **Development:** Web applications, mobile applications, REST APIs, and database-driven systems.
- 📱 **Mobile:** Flutter & Dart for cross-platform application development.
- 🌐 **Web:** PHP, MySQL, JavaScript, React, and Next.js.
- 🤖 **Research Interests:** Machine Learning, DDoS Detection, Cybersecurity, and Blockchain.
- 👨‍🏫 **Education:** Teaching programming and helping learners understand technology.
- 🚀 **Goal:** Building useful software while continuously growing as an engineer and researcher.

> "Build with purpose. Learn continuously. Create solutions that matter."
